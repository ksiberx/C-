ДОПОЛНЕНИЕ К ЛАБОРАТОРНОЙ РАБОТЕ — БАЗА ИГР

В архиве обновлён Games.App/Program.cs. Остальные проекты сохранены.
Добавлены поиск по названию, студии, студии+названию, жанру и году;
фильтр по режиму игры; максимальные/минимальные продажи; топ-3;
добавление с проверкой дубликата; изменение параметров; удаление с подтверждением.

Как использовать:
1. Распакуйте архив.
2. Откройте GamesDatabase.sln в Visual Studio.
3. Проверьте строку подключения в Games.Data/GameContext.cs.
4. Если база GamesDb уже создана предыдущим заданием, запускайте Games.App.
   Программа применяет миграции при старте и показывает меню.
5. Если таблица ещё не создана, сначала выполните инструкции по миграциям
   из предыдущего README.txt.

Для удаления и редактирования игра ищется по точному названию и названию студии.
При добавлении такая же пара названия+студия считается дубликатом.
